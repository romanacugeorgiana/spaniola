# Español con Georgiana

HTML exercises for Spanish language practice. Each exercise is a self-contained HTML file in the `exercitii/` folder.

## Structure

- `index.html` — landing page linking to all exercises
- `exercitii/` — individual exercise HTML files (no encryption, files are public)

## Adding a new exercise

1. Create the HTML file in `exercitii/your-exercise-name.html`
2. Add a card for it in `index.html` inside the `.grid` div

No build step needed — files are served directly.
